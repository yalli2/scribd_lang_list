# Scribd Language Library · 언어별 교재 찾기

13개 언어(스페인어·영어·프랑스어·독일어·이탈리아어·포르투갈어·일본어·중국어·한국어·러시아어·아랍어·라틴어·카탈루냐어) × 8개 분야(문법·회화·어휘·문화·시험대비·종합교재·동사·읽기)별로 Scribd에서 **100페이지 이상** 문서만 골라 보는 검색 허브입니다.

- **언어별**: 분야 카드마다 영어/현지어/교재명 키워드 링크
- **한눈에 보기**: 언어 × 분야 표
- **내 목록**: 찾은 문서 주소를 저장(브라우저 저장), JSON/CSV 내보내기·불러오기
- 분량 필터(100+ / 4–100 / 전체), 화면 언어 변경(한국어·English·Español)

이 사이트는 Scribd 검색 결과로 연결되는 링크 모음이며 문서를 보관하거나 배포하지 않습니다.
